# 透明玻璃半球 Emoji 1.7.0

根据原始 `glass-emoji.html` 设计参考制作。直接沿用示例的 SVG 球体轮廓、左右眼白／眼睑路径、椭圆虹膜和反光比例，以及玻璃、暖光、眼眶、眉毛和底圈的渐变与滤镜。遵循 [插件规范](../../docs/PLUGIN_SPEC.md)，使用 SDK v2 公开接口。任务栏自动贴合需要 SDK 2.2.0；旧版 SDK 回退到画布底部。

两只眼睛保留示例中的大小、高度和形状差异，不再使用之前的通用椭圆眼球。眼神会跟随 SDK 提供的鼠标位置，自主环顾并自然眨眼；眉毛保持示例的倾斜与渐细轮廓，随表情改变抬升和弧度。嘴巴始终为闭合嘴唇的一条小曲线，仅改变嘴角和弧度，没有张嘴或点击粒子。

1.6.1 恢复五官的转动细节：眼睛快速锁定方向，脸部稍后跟随；左右转头、抬头低头和歪头分别平滑变化。双眼、眉毛、嘴巴、眼眶和脸颊使用各自的球面投影，近侧与远侧的压缩、倾斜和位移不同。瞳孔可完整左右环顾、上下追踪、轻微游移与缩放；眨眼／眯眼带闭眼弧线，左右眉毛和嘴角保留不对称的动作与延迟。中性姿态保持参考 SVG 的五官路径和比例。

光影直接使用示例的分层实现：底部暖黄体积光、眼眶金色柔光、脸颊高光、玻璃表面片状反射、青蓝紫色弧面与薄底圈。底圈去掉上侧亮弧，只保留下侧前缘的弧线和光泽。颜色缓慢变化，增加柔和流彩。去掉整页底色、整片背景光晕和地面倒影，保留玻璃边缘本身的柔光；PNG／桌面背景仍透明。

包内文件均为本地资源：

```text
glass-dome-emoji/
  plugin.json
  main.js
  glass.svg
  README.md
```

将整个文件夹复制到 `%LOCALAPPDATA%\DesktopArt\canvas\plugins\`，在插件管理中加载“透明玻璃半球 Emoji”。SVG 通过当前插件版本的本地地址读取，ID 在每次激活时加唯一前缀，避免共享页面中的渐变和裁剪冲突。异步读取支持中止；卸载和热重载由 SDK 清理图层、动画、事件与订阅，自建的可见性监听也会移除。

默认位于主显示器下方、水平居中。任务栏在底部显示时，球体下缘贴合其顶部；隐藏时贴合桌面底部。使用 SDK 2.2.0 的 `scene.desktop.rect` 和 `bottomEdge`，并随原生任务栏几何更新位置。以实际绘制下缘对齐，扣除 SVG 底部透明留白。宽度约 560 像素并随可用区域缩小，上限 30 FPS。设置使用公开 `api.settings`，没有设置界面：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `centerX` | `0.5` | 水平位置，画布宽度比例 0～1 |
| `bottomGap` | `0` | 与任务栏顶部或桌面底部的间距，物理像素 |
| `maxRadius` | `280` | 为兼容旧设置保留；新版最大宽度为此值的两倍 |
| `scale` | `1` | 尺寸倍率 0.2～2 |
| `fps` | `30` | 动画绘制上限 10～60 |

用户已确认真实任务栏检测测试通过，1.7.0 启用自动贴合。保留 1.6.1 的 SVG 五官、独立球面转动、微表情和只绘制下侧的底圈；没有使用早期 Canvas 五官版本覆盖当前效果。

插件为背景视觉层，输入穿透；Shell 图标、点击、选择、右键和拖放由原生桌面处理。SDK 鼠标事件主要来自盒子输入窗口；盒外没有事件时会自主环顾。没有第三方库、外部网络请求、绘制接管或内部 RPC。

本地预览：`demos/glass-dome-emoji.html`（保留在工作区，不随仓库发布）。预览页的深色／浅色／棋盘背景和模拟任务栏只用于查看效果，不会打包为插件背景。
